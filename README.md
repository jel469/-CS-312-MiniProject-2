# Joke Finder Mini Project

A simple Node.js web app that fetches jokes from [JokeAPI](https://sv443.net/jokeapi/v2/) and displays them using EJS.
This was built with Express, Axios, and EJS for this CS312 mini-project in regards to API integration and server-side rendering.

## Core Features

- Filter jokes by category, type, keyword, and amount
- Optional blacklist flags and safe mode
- Server-side API requests with Axios
- Success results and error messages rendered with EJS
- Responsive layout for desktop and mobile

## Setup

```bash
npm install
npm start
```

Open [http://localhost:3000](http://localhost:3000).
